# RUN Campus Connect — Exhaustive Codebase Inventory

This document provides a comprehensive, file-by-file catalog of every source, configuration, script, and test file in the **RUN Campus Connect** repository, defining its location, architectural role, primary exported symbols, and operational responsibilities.

## 1. Root Workspace Configuration Files

| File Path | Description & Role | Key Dependencies / Content |
| :--- | :--- | :--- |
| `pubspec.yaml` | Flutter package manifest. Defines application name (`run_campus_connect`), version (`1.0.0+4`), SDK constraints (`sdk: ^3.7.2`), production dependencies (Riverpod, Firebase, Dio, Cloudinary, Hive, Shorebird), dev dependencies, launcher icons, and asset declarations. | Flutter SDK, Riverpod, Firebase |
| `pubspec.lock` | Pinned dependency tree lockfile ensuring reproducible builds across all developer workstations and CI runners. | Generated by `flutter pub get` |
| `firebase.json` | FlutterFire configuration mapping Flutter target platforms (Android, iOS, Web, macOS, Windows) to Firebase project `run-campus-connect`. | FlutterFire CLI |
| `firestore.rules` | Security rules for Cloud Firestore. Governs document permissions, atomic counter limits, participant privacy, and administrator access. | Firebase Security Rules v2 |
| `storage.rules` | Security rules for Firebase Storage buckets. Restricts avatar and post media uploads to authenticated owners while permitting public reads. | Firebase Storage Rules v2 |
| `shorebird.yaml` | Shorebird Over-The-Air code push configuration specifying the unique application GUID (`7a40f5ba-824d-412d-8582-59e44db084b6`). | Shorebird CLI |
| `analysis_options.yaml` | Static analysis ruleset enforcing `flutter_lints` and strict typing standards. | Dart analyzer |
| `README.md` | Top-level repository overview and entry point pointing to the `docs/` technical documentation suite. | Markdown |
